# Kedai 0.3.0-A-beta — 变更说明(2026-09-13)

> 前序:[0.3.0-beta-变更说明.md](0.3.0-beta-变更说明.md)、
> [0.3.0-beta-后续修复-变更说明.md](0.3.0-beta-后续修复-变更说明.md)。
> 本版是 0.3.0-beta 的**加固与修复版**:修掉卡片生成截断、补齐数据安全与工程门禁,
> 并完成一次三轮架构评审后的分批治理。版本号 `0.3.0-A-beta`(semver 预发布后缀,
> 与 0.3.0-beta 同密钥可覆盖安装)。

## 一、用户可感知的变化

### 1. 任务模式支持命令执行(bash)
`bash` 在任务模式默认策略下下发(仅此工具按名开例外,其它危险工具仍被排除)。
**危险命令的硬门未动**:删除/格式化/提权/包管理在任务模式下直接拒绝(无 UI 确认通道),
普通命令(ls/echo/mkdir 等)经任务白名单授权执行;仍受 `exec_enabled` 总开关约束(默认关)。

### 2. 角色卡「掉格式」修复(Android 真机复现)
根因:卡片要求「整个回复有且仅有一个 JSON」,而 Android 首装默认 `max_tokens=1024`
把 JSON 腰斩,卡片解析器全回退失败 → 报「丢格式」并把叙事原文当纯文本显示。
修复:`generate-raw` 路径专属下限 **8192**(不动用户设置语义)、
`finish_reason=length` 时**预算翻倍重发**(封顶 32768、最多 2 次)、重发失败或用尽时
**仍返回 200 + 最后一次文本**(卡片自带解析器可救半截,整体报错更无用);
显式 `max_tokens=0` 返回 400。新增诊断日志与 `kedai.tavern-call-log` 记录
(注入条目数 / 产出长度 / 截断重试),卡片再报丢格式时可直接区分「世界书未注入」与「被截断」。

### 3. 「更新内容」文案更新(2026-09-13 治理批次)
关于页「更新内容」改为反映本轮工程治理的用户可感知结果:用量统计事务化、消息删除的
孤儿数据清理、截断自愈统一、引擎异常状态迁移留痕、内部结构收敛(任务引擎宿主能力拆分 /
Agent 引擎依赖分组 / 前端弹窗开关单点)、ESLint 与依赖扫描加固、EJS 冻结门禁。
文案在 `web/src/components/settings/AboutSection.vue` 的 `changelog` 数组,依据本轮
四份变更说明(见 §七)。

## 二、稳定性与数据安全(加固项)

- **API Key 不再被静默清空**:换机/换用户后密文解密失败时,保存设置不再用空值覆盖
  磁盘密文,而是保留原密文并留日志提示重填(此前会永久丢失密钥且仅一行 stderr)。
- **生成中断不再卡死会话**:`pending_runs` 占位改 RAII(drop 守卫),引擎异常/panic
  也会清理,修复「一次失败 → 该会话此后所有发送都 409」。
- **生成期间可正常保存设置**:连接器读锁改为快照,不再跨整轮流式生成持有
  (此前保存设置会阻塞到生成结束)。
- **长会话/长列表更流畅**:补齐 `sessions(character_id, updated_at DESC)`、
  `tasks(character_id)`、`tasks(status)` 索引;世界书列表条目数随编辑实时更新。
- **无界增长收敛**:压缩摘要(每会话保留最近 20 条)、命令审计(最近 2000 行)、
  会话删除时清理回退快照 / 契约日志 / message 作用域变量。
- **写连接锁中毒可恢复**:中毒时留痕并对未完成事务显式 `ROLLBACK`(此前直接续用)。

## 三、工程与供应链

- 依赖漏洞修复:`sanitize-html 2.17.7`(存储型 XSS 公告)、`nanoid 3.3.19`;
  `npm audit --omit=dev` 归零并进检查(警告档);`cargo audit` 默认**硬门禁**。
- **双 Cargo.lock 对齐**:17 个 crate 分歧清零(含已被 yank 的 `chacha20 0.10.1`
  与 `cc`/`find-msvc-tools` 构建工具链);新增 `tools/check-lock-sync.mjs` 门禁
  (0 漂移为基线,新增即 FAIL)。
- **迁移元测试**:冻结 0.3.0-beta 建表基线,老库升级后与全新库逐表比对结构指纹,
  防「加列漏写迁移」只在老用户机器上炸(`tests/schema_migration_meta.rs`)。
- CI 工作流落盘(`.github/workflows/ci.yml`,仓库配置远端后自动生效);
  构建清理路径跟随 `-RustTargetDir`;本机临时脚本/构建日志不再污染仓库。
- 新增 [威胁模型与残余风险.md](威胁模型与残余风险.md)(活文档)与
  `docs/模式提示词边界.md` 的预览口径澄清。

## 四、兼容性

- **不改 API 线格式**;不改授权风险分级(`bash` 恒 Dangerous)、不改 `allowlist` 档语义。
- **DB schema 变更仅限**:新增三个索引 + 保留策略 DELETE;老库经幂等迁移自动补齐
  (迁移元测试把关)。无破坏性结构变更。
- `generate-raw` 失败语义放宽:重发失败由 502 变为 200 + 半截文本(响应形状不变),
  详见 `API.md` 端点说明。
