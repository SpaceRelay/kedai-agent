## 四、新增内置工具的登记清单(易漏,勿凭记忆)

新增工具时,工具名需同时出现在下列位置 —— 漏改会**静默降级**(不报错,只是行为变弱):

1. `tools/mod.rs::register_builtin_tools` — 注册定义与执行器(**必改**)
2. `tools/permissions.rs::default_risk` — 风险级(**必改**:未登记一律落 `_ => Dangerous`)
3. `tools/tool_sets.rs` — 场景白名单(只读工具需进 `READONLY_SCOUT`/`SUBAGENT`/`REFLECT`,
   否则规划侦察 / 子 agent / 反思看不到它)
4. `tools/registry.rs::tool_when` — 「何时调用」指南文案(漏改则回退 description)
5. `tools/registry.rs::render_kind_for` — 前端渲染意图
6. 前端 `web/src/agentFlowTools.ts` / `AgentFlowSection.vue` — 流程白名单提示

> 收敛方向(批次 4 候选):把 1–5 合并为单一工具清单结构,或用元测试做穷尽性检查。
