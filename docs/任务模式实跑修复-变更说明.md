## 2. 行为变更与兼容性

- **F2 是唯一默认行为变更**:任务模式默认不再继承 `prompt_floors.json` 注入。
  依赖该注入的用户任务文案风格会变化;需要旧行为时在设置里把「任务继承提示词注入」
  切为「继承」(或 `task_prompt_inject_enabled: true`)。旧 settings.json 无此字段,
  serde default 零迁移。
- F5 为向后兼容的 API 扩展:`mode` 缺省/空 = `append`(旧客户端请求零变化);未知值 400。
- F6 只影响 `task_llm_calls.finish_reason` 的填充;截断自愈仍只认 `length`,行为不变。
- F1/F3/F4/F7/F8 为纯修复,不改变对外契约。
